# Poker Application

This is an Android Studio project for the existing Java poker game.

## Run in an emulator

1. Open this folder in Android Studio and allow Gradle sync to finish.
2. In **Tools > Device Manager**, create and start an Android virtual device.
3. Select the device and run the **app** configuration.
4. Tap **Join Game**, then **New Game** to start a hand.

The app's Java sources are under `app/src/main/java/com/example/example_1`, with Android resources under `app/src/main`. The card faces, card back, and poker-table artwork are original local assets in `app/src/main/res/drawable`. The older `SpinAndGo.java` and `test.java` files are not wired into the main app.
